# Visualization_project

# who is the target audience: 
 -researchers in human–wildlife coexistence, since explaining large carnivore attacks requires relating species, location, time and human activity to environmental and socioeconomic indicators such as forest cover, agricultural land and income level.
 -an interactive visualization tool helps them discover patterns in this high-dimensional data that an automated solution could miss, and these insights can inform evidence-based safety guidelines and policies to reduce future conflicts.
how to show the data: a map where we spot the attacks, color grading the areas with attacks; by clicking on each country you can find more insights, viz type tbd
